# Animated background resources

## Knowledge

- [MDN: Including vector graphics in HTML](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Structuring_content/Including_vector_graphics_in_HTML)
  Primary reading for the first lesson. Explains pixel-based images versus SVG drawings, with visual examples.
- [MDN: SVG groups (`<g>`)](https://developer.mozilla.org/en-US/docs/Web/SVG/Reference/Element/g)
  Explains how shapes are grouped and transformed together. Use when discussing a twig that sways as one piece.
- [MDN: SVG transforms](https://developer.mozilla.org/en-US/docs/Web/SVG/Reference/Attribute/transform)
  Documents translation and rotation around a chosen point. Use for distinguishing leaf placement from its pivot.
- [Anime.js: Animation](https://animejs.com/documentation/animation/)
  Official animation API. Use for understanding how JavaScript changes a drawing’s rotation over time.
- Local implementation: `index.html`, `styles.css`, and `script.js`.
  The source of truth for this particular portfolio: the `#sprig` SVG template, `.forest-backdrop` photo layer, and `[data-sway]` animation targets. The first lesson preserves the template’s original coordinates as an explanatory example.
